% figstyle.tex -- shared preamble of the standalone figure sources.
% Each figure is a self-contained LaTeX document:   \documentclass{standalone} \input{figstyle}
% Compile it (pdflatex) and copy the PDF one level up; build_figures.ps1 does this for all.
%
% Design rules used throughout
%   * every figure is drawn at its final printed size (<= 16 cm wide), so the font sizes
%     below are the sizes the reader sees: text 9 pt, smallest labels 8 pt;
%   * sans-serif lettering (Helvetica clone) as recommended by Elsevier for artwork;
%   * no titles inside the artwork (the caption carries the title) and no hard-coded
%     section or equation numbers (the caption refers to them through \ref).
% =====================================================================================
